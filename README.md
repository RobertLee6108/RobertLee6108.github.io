# RobertLee6108.github.io

This is a GitHub Pages blog powered by Jekyll.

## How to use

-   **Posts**: Add new blog posts to the `_posts` directory. The filename must follow the format `YYYY-MM-DD-title.md`.
-   **Configuration**: Edit `_config.yml` to change the blog's title, description, and other settings.
-   **Pages**: You can add new pages like the `about.md` page.

Your blog will be available at [https://RobertLee6108.github.io/](https://RobertLee6108.github.io/).
